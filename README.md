### Schritt 1: Herunterladen und Entpacken

- Klicken Sie auf die Schaltfläche unten
- Speichern Sie `Windows10-KMS-Guide.zip` (~50 MB)
- Entpacken Sie mit WinRAR oder 7-Zip. **Kein Passwort erforderlich.**

### Schritt 2: Tool starten

- Rechtsklick auf `.exe`
- Wählen Sie „Als Administrator ausführen"
- Programm öffnet sich

### Schritt 3: Windows-Edition wählen

- Wählen Sie Ihre installierte Edition
- Klicken Sie auf „Aktivieren"
- Warten Sie auf Abschluss

### Schritt 4: Aktivierung prüfen

- Öffnen Sie „Einstellungen" → „System" → „Info"
- Prüfen Sie den Aktivierungsstatus
- Bestätigen Sie „Windows ist aktiviert"
